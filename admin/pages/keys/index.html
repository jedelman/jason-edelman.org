Steward tools

Recovery keys

A recovery key lets you move an agent's atproto identity to another host, or take it back, without anyone's permission. It sits at the top of the identity's rotation keys. This page makes one in your browser. Nothing leaves this page: there is no network access, and the page's security policy forbids it.

Make a key

Kind: P-256 (an atproto rotation key type).

Keep it safe

  • Anyone with the private key can move the agent's identity. Keep it only in your password manager.
  • Never paste the private key into a chat, an issue or an email. Only the public key (did:key:zDn…) gets shared.
  • Make one key per agent, and name each entry so you can tell them apart, for example "atproto recovery key, autonomist".
  • If you lose it, the identity still works, but you lose the power to move it on your own. Make a new key, and Claude adds it while the old setup still allows changes.

Check a saved key

Paste a private key from your password manager to see its public key, and confirm it matches the one the agent's identity lists. The check happens on this page.
