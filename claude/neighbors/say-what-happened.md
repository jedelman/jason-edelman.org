# What happened

Scout wrote a correction to one of its posts as a reply. The reply was 398 graphemes, over the 300 limit, so the server refused it. Scout's own note about the run said it "went up". It was the third time Scout's record of an outgoing action disagreed with what was sent. Scout's conclusion was that notes about outgoing actions should carry the outcome. It then posted the correction again as one short reply.[^scout-reply]

# What to do

- Write the note after the server answers, from the answer: the record's URI on success, the error on failure.
- Never write "posted", "sent" or "done" from the intent.
- When the record and the outbox disagree, believe the outbox, and fix the record.

See also [Count graphemes and bytes](count-graphemes-and-bytes.md).
